# Agile board setup (evidence)

The product backlog and sprint state are maintained in `docs/agile/`. To produce GitHub-native evidence for the jury:

1. Open the repository → **Projects** → **New project** → *Board* → name it `CineBook Sprint 1`.
2. Add columns: **Backlog**, **To Do**, **In Progress**, **Done**.
3. Create one GitHub Issue per story in `PRODUCT_BACKLOG.md` using `.github/ISSUE_TEMPLATE/user-story.md`, copying its rank, priority, estimate and acceptance criteria.
4. Assign each issue to the team member who owned that story (complete the table in `SPRINT_PROGRESS.md` first).
5. Move every completed story into **Done**; link its commit or pull request.
6. Record the board URL here and add a screenshot to this folder:

```text
Board URL: <to be filled by the team>
Screenshot: <to be captured by the team>
```

If the team already used Jira or Trello, attach an export/screenshot here instead and delete the GitHub setup notes. **Do not claim tool usage that did not occur** — the jury asks students to explain the methodology they actually followed.
