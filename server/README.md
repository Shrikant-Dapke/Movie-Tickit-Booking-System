# CineBook API

Run `npm install`, configure `.env` from `.env.example`, then `npm run dev`.

Seed demo data from the repository root with `npm run seed` (or from this directory with `npm run seed`). The seed creates six demo movies, showtimes for three days and `admin@cinebook.demo` / `Admin123!`.

The API listens on port 5000 by default. See the root README for endpoint summary. Do not use demo credentials or the fallback JWT secret in production.
